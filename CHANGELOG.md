# Changelog

This changelog records notable repository and application changes. It does not imply that every planned roadmap item is implemented.

## Unreleased

### Documentation and project maintenance
- Expanded the project overview and command documentation.
- Added architecture, data-model, build, testing, limitations, roadmap, and troubleshooting guides.
- Expanded contribution, community conduct, and security policies.
- Added a Makefile for repeatable local builds.
- Added support guidance and a repository issue-template configuration.
- Added editor configuration and a C formatting baseline.

### Current application status
- The application remains a single-file C11 terminal prototype.
- It continues to use fixed-size in-memory buffers.
- File persistence and automated behavioral tests are not implemented.
