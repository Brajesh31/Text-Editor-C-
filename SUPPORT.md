# Support and Questions

## Before asking for help

1. Read the [README](README.md) and [Command reference](docs/COMMAND-REFERENCE.md).
2. Check [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Confirm that you are compiling the current source rather than running an old executable.
4. Reproduce the issue with the smallest possible input sequence.

## Where to ask

- Use GitHub Issues for reproducible bugs and concrete feature proposals.
- Use a pull request for a focused code or documentation improvement.
- For a security concern, follow [SECURITY.md](SECURITY.md) and do not publish exploit details publicly.

## What to include

For build issues, include your operating system, compiler name and version, exact command, and complete relevant error output.

For runtime issues, include the commands or text entered, expected behavior, actual behavior, and whether the issue is repeatable.

## Project scope

This is a small educational C project. It is not a commercial product and does not currently provide file persistence, guaranteed data recovery, or a formal support SLA. Questions and contributions are welcome, but response times are not guaranteed.
